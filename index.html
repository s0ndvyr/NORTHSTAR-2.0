A QUICK HEADS-UP

Good key.
Different obstacle.

Some schools block websites from talking directly to Canvas. A correct token alone can’t bypass that browser restriction.

The included bridge is self-hosted and sends the token in an authorization header, never through a public CORS proxy or URL.

Available: courses, assignments, submission status, supported writing/URL/file submissions, classic quiz attempts, and graded discussions.
Limits: StudentVUE is an import, not a live sync. New Quizzes, external LTI tools, and unsupported Canvas question/submission types still open in Canvas.
